# KWAgent v0.6.1

所有角色共用 `/data/python/.venv`，通过 uv 统一管理依赖，安装和升级包对全部角色生效。角色并行准备时共用初始化操作，重启保留已安装的包。

共享环境随 `/data` 持久保存，也可以单独挂载到 `/data/python`。完整备份、恢复和权限准备均涵盖该目录。脚本、浏览器登录 profile、截图及下载仍保存在各自工作目录。

固定系统说明与 Python Skill 统一使用共享解释器路径，并说明 shell 激活和 `run_code` 调用格式。镜像中的 Python、uv、Playwright 和 Chromium 版本保持配套。
