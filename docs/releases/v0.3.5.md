# KWAgent v0.3.5

- MCP 发送边界递归将 `type` 放在普通字段之前，兼容 Lagrange 的多态 JSON 绑定；正文、数组顺序、媒体 URI 和字符串载荷保持完整。
- 操作意图记录实际序列化参数，调用方的原始对象保持完整。
- Lagrange Skill 明确群聊、私聊、临时会话的参数、片段结构、字段顺序、引用提及与嵌套转发规则；能力目录与工具说明同步提供格式提示。
- `Endpoint invocation failed` 按执行结果未知处理，保留原始错误和核实入口，避免将通用异常作为自动重发依据。

数据库继续使用 Schema 3，自动压缩继续由 Harness 处理。已有失败和未知操作保留历史，不自动补发。
