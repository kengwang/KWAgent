# KWAgent v0.3.1

- 新增 `kwagent-life` Skill，说明初始化、实时交流、来源、关联 ID 和计划的用法，并随角色会话提供加载入口。
- 补充 Lagrange Skill：内部输出与实际发言分别处理，新的询问与提及不会被旧的场合判断或后续计划遮蔽。
- 修复成功工具结果经负载预览保存后丢失观察语义的问题。判断前读取完整对象并校验角色归属及 SHA-256，兼容既有事件。
- 新消息到达时取消收尾记忆整理的辅助请求，及时接纳输入；保留原始经历、已提交分片及后续整理进度。
- 连续性工具明确区分正文和记忆、计划、来源等关联 ID，保留角色人格、修订历史和错误检查。

兼容 Harness `0.2.2-alpha.2`，Bun 管理依赖，Node.js 运行。数据库继续使用 Schema 3。部署前创建完整备份；服务器通过固定 digest 的 GHCR 镜像或镜像加速地址升级。
