# KWAgent v0.5.1

原始群消息被实际接纳处理时添加系统表情 `424`。当前活动正常完成，且发送结果得到确认后，先取消该消息的 `424`，再添加 `282`。失败、中断或发送结果未知时保留未完成状态。

表情操作按角色独立排队，通过 Harness 的原生执行器、工具守卫与 Milky 实际 Schema 执行，参数为原群号、消息序号、`reaction_type="face"` 及 `is_add`。模型无需另行维护这些状态，也不会为状态反馈额外推理。

每条原始消息保存进度和实际执行状态。重复事件及重启不会重复执行已经尝试的操作；重启前结果未知的调用保留未知，不自动重放。取消 `424` 未成功时不会添加 `282`。表情失败作为操作记录保留，前台交流继续进行。自身表情回流事件仍保存为经历，默认不唤醒角色。

本次继续使用 Schema 4，进度记录、修订及工作索引进入现有数据库备份。服务器使用 GHCR 镜像部署，保留已有角色、原会话与启停状态。
