# v0.8.1

后台任务完成、失败或取消后自动送达结果并唤醒角色。执行器指导、后台句柄、任务查询说明、完成通知及生图 Skill 统一要求不要轮询 `job_output` 或 `job_list`，也不要通过 sleep、`wait:true`、循环、其他后台程序或定时计划反复检查。

依赖任务结果时结束当前活动，收到通知后继续；结束回复不会取消后台任务。通知已经提供状态、结果预览及完整负载引用，具体内容不足时才按需读取一次。用户明确要求查看任务时仍可读取，取消和查询接口保持可用。是否先向交流对象说明正在处理，继续由角色自行判断。

本次调整模型指导和结果说明，任务执行、取消、通知去重及工具权限沿用现有行为。数据库沿用 Schema 4，角色、Session、模型预设和运行数据继续保留。
