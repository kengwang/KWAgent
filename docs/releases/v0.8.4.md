# v0.8.4

“全局模型方案”作为独立入口管理全部角色共享的配置，角色页面按用途下拉引用。新建角色需要选择全局聊天方案，已有直接配置保留当前选择，思考等级继续支持角色独立覆盖。

全局方案和角色表单保留各自的编辑草稿，切换角色、进入全局管理及返回角色时继续编辑。角色活动、错误和导航与全局管理分开显示。方案数据沿用现有全局记录，不增加角色副本或数据库迁移。

每步背景使用稳定基线和增量更新。已经提供的记忆、人物和计划正文通过内容引用复用，后续仅发送新条目、修订及当前选择变化；模型历史保持追加，完整快照继续持久保存。重启从已接纳记录恢复，Harness 压缩移除基线后重新建立当前背景，取消前未投递的更新不会推进状态。

记忆整理将稳定的既有资料放在新来源之前，跳过纯工具调度和空内部输出的模型提取，避免对相同内容生成重复修订。原始经历和未完成分片保留。辅助请求使用模型支持的最低思考等级，对话思考等级保持角色配置。

用量显示为“总处理 Token（含缓存）”，说明其中包含主对话和自动记忆整理等辅助请求。缓存读取仍属于处理量，费用以提供商账单为准。

真实官方模型在 `high` 等级下验收，背景从首次约 28 KB 降为后续 328–444 字节，热身后的输入缓存命中率约 98.7%。首次基线和实际新增内容仍需要输入；不设置新的 Token 上限，不主动触发压缩。
