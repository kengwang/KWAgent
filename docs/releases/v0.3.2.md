# KWAgent v0.3.2

- 自动记忆整理使用与提交校验一致的完整 JSON Schema，包含严格的会话形状、关联字段、状态和修订规则。
- 新建连续性记录的 `id` 支持省略或 JSON null，修改仍需实际标识与当前修订号。
- 辅助整理、检索与压缩选择模型实际支持的 `off` 思考档位，给结构化输出和摘要保留预算；聊天主循环保持独立的思考设置。DeepSeek 兼容接口可通过 `KW_CHAT_THINKING_FORMAT=deepseek` 明确声明协议。
- 保留 v0.3.1 的运行 Skill、工具观察来源修复和新输入打断收尾整理的行为。

数据库继续使用 Schema 3。升级保留原始经历、整理分片、角色和 Session；压缩前继续保存必要记忆。
