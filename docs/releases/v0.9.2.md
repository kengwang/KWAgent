# v0.9.2

角色背景提供身份、人格、当前生活与本次唤醒直接关联的事项。历史记忆、人物、世界资料、表达与反思通过工具查询，原有 memoryTokens 保留兼容。背景协议升级为 v2，按真实标识组织，原会话追加新版基线，压缩时机由 Harness 判断。

memory_recall 返回有界摘要页及 nextCursor，默认本地检索十条，最多五十条。摘要提供真实标识、修订号、命中片段与读取入口；正文、来源和历史分层读取，游标绑定条件及检索版本。Panel 支持分页、失效提示、正文、来源与修订冲突，搜索默认不调用模型扩展。

自动整理共用一种业务对象格式，宿主合并变化字段与原来源，并执行完整校验。固定批次保存输入、草稿、完整响应和尝试进度，每轮最多一次修正；重启可继续提交已保存的响应。变更与分片完成记录原子提交，不自动合并或删除现有记忆。

继续使用 Schema 4，保留正式角色启停、会话、绑定、模型配置和运行资料。升级前执行完整备份，固定版本镜像通过既有 Compose 部署至 1panel-network。真实模型验收中的 workbuddy2api 返回429模型额度不足，该项按用户要求记录为阻塞，未使用替代结果。
