# KWAgent v0.5.2

所有角色统一使用 Harness 自带的 PTC 工具模式，普通发言、管理员请求及持续活动使用相同的工具目录。角色通过 `run_code` 和工具 SDK 调用能力，程序完成时返回 JSON，并根据具体子调用回执判断发送结果。

管理员 QQ、真实发送者、重要操作的判断及角色表达要求由每步提示词提供。工具可用性由 Harness 和实际连接决定。来源、字段、版本及数据库一致性继续按业务 Interface 校验。

消息处理状态通过活动记录展示，不自动添加或撤销消息表情回应。保留现有角色、会话、记忆与安排，数据库继续使用 Schema 4。部署使用固定提交的 GHCR 镜像，不上传工程源码。
