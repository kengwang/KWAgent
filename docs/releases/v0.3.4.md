# KWAgent v0.3.4

- 模型上下文容量和输出长度交由 Harness 适配器及模型设置解析，角色运行、检索与记忆整理不再指定固定输出上限。
- 专用角色 preset 完整继承 Harness 的压缩配置，MindCompaction 仅在宿主自动压缩前保存必要记忆。
- 容量判断与溢出恢复由 Harness 执行；KWAgent 保留实际请求的预算观测。
- 移除 KWAgent 的手动压缩管理动作，运行 Skill 和验收流程统一使用宿主自动压缩。
- `role.prepare` 提供生效的模型信息、角色输出设置与压缩策略，便于检查原会话恢复后的配置。

数据库继续使用 Schema 3。角色、Session、原始经历与发送回执保持持久化；部署通过完整备份与固定镜像更新。
