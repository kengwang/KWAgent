# KWAgent v0.5.5

每次模型步骤只提供当前角色背景。准备下一步骤后，插件通过 Harness 的公开 Session surface replacement 让旧的 `kw-life-state` 退出模型输入；原始记录、正文负载、版本和来源保持可读。真实消息、工具回执、其他插件的背景贡献保持完整。

生产诊断发现，一份背景约占 9300～11200 估算 Token，同一会话已运行 87 个步骤，请求曾达到 417159 估算 Token。Harness 0.2.2-alpha.2 会追加发生变化的运行背景，因此需要由背景的提供者管理旧版本的有效性。

恢复当前会话时使用同一规则处理尚在输入中的旧背景。保持角色状态、Session、记忆预算和工具配置；压缩时机由 Harness 判断。

验收命令：`node scripts/ci.mjs` 和 `node scripts/verify-step-context.mjs`。后者使用真实 Harness 和模型验证连续输入与同一 Session 重启，QQ 与空间调用由隔离工具守卫禁止。
