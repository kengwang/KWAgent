# KWAgent v0.8.0

新增独立“模型配置”页面，可以自行填写 API 地址、API Key 和模型名称，保存为聊天、视觉或生图预设。角色分别选择所需预设，推理等级继续支持角色单独配置。Key 使用 Harness 凭据存储，列表、读取及业务数据库不包含明文。

新增 `image_generate` 与 `image_edit`，使用角色选定的 OpenAI Images 兼容接口。支持图片生成、多图参考编辑、透明 PNG 蒙版、图片规格及返回格式配置。完整响应和输出图片持久保存，工具返回媒体引用，由角色自主决定是否检查或发送。

图片操作沿用五秒自动转后台、完成通知、取消及活动追踪。已有角色、会话和原模型配置保持可读，数据库沿用 Schema 4。详细配置见 `docs/models.md`。
