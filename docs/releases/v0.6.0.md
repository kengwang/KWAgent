# KWAgent v0.6.0

每个角色拥有工作目录中的持久 `.venv`，使用 uv 管理额外 Python 依赖。镜像提供 Python 3.11、固定版本 uv 0.13.7、Python Playwright 1.64.1 与匹配的 Chromium；角色准备时即可使用，无需临时下载浏览器。

固定系统说明给出当前解释器、激活方式和依赖安装方法，`kwagent-life` 补充 Python 浏览器示例。角色可以自主使用浏览器阅读页面、操作控件、截图与下载，登录 profile 保存在自己的工作目录。

现有 `/data` 挂载涵盖 venv、工作文件及浏览器 profile；uv 缓存位于 `/data/cache/uv`。Compose 提供 1 GiB 共享内存，生产继续只接入 `1panel-network`。环境、浏览器登录资料与 Python 缓存的 Git、镜像排除规则同步维护。

CI 使用实际 Chromium 检查页面交互、截图、下载、依赖安装和角色隔离，并在复用持久卷、禁止外网的全新容器中验证依赖和浏览器 profile 恢复。正式角色和会话保持原样。
