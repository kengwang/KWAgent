# KWAgent v0.7.0

角色可以通过 `run_code` 的 `run_in_background:true` 显式提交后台程序。普通程序默认等待五秒，尚未结束时返回任务句柄，原程序继续执行。后台期间角色可以处理其他输入，结束后通过持久事件接纳实际结果。

任务控制保留 `job_list`、`job_output`、`job_kill`。Panel 活动页提供任务状态、结果引用、发起活动和取消入口；管理动作提供 `task.list`、`task.read`、`task.cancel`。完整结果及延后图片保留在负载存储中，默认仅装配有界预览。

后台子调用使用原角色的独立工具准入集合和取消信号，通过 Harness 公开 PTC runtime 与工具流水线执行。SDK 和直接入口说明复用公开 PtcExecutor，后台执行日志保存为插件记录，可以跨越模型 turn。Harness 源代码保持完整。

暂停、停止、会话管理和维护会取消任务并等待释放资源。任务结果持续保存；强制终止后未结束任务标记中断，程序不自动重放。任务与结果事件使用稳定标识，重启继续处理尚未接纳的结果。

部署参数 `KW_ASYNC_FOREGROUND_WAIT_MS` 默认 `5000`，仅控制前台等待。具体工具及 PTC 原有执行超时继续生效。数据库保持 Schema 3，备份包含任务、Session 和完整负载。
