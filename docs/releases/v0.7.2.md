# KWAgent v0.7.2

后台任务句柄明确说明完成结果会自动作为新输入送达，角色可以继续独立活动或结束当前回复。任务查询同时在结构化结果和模型可见正文中说明目标状态：运行中、取消中、空正文及查询等待超时均不构成重新提交原操作的依据。

执行器指导、`job_output` 说明和 `kwagent-life` Skill 共同说明按需读取、等待超时及查询程序和目标任务的区别。任务控制能力保持可用，角色根据实际结果自主决定是否重试和交流。

角色预计任务耗时且认为有必要时，可以自主选择在启动后简短告知正在处理。系统不自动发送等待消息，也不要求每项任务都先回复；告知内容遵循实际执行进度。

沿用 v0.7.1 的完成通知去重与已有 turn 续接修复。数据库保持 Schema 4，原角色、Session、任务和配置保留。
