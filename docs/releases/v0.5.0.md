# KWAgent v0.5.0

每个角色可以在 Panel 配置预注入 Skill 和管理员 QQ，并从 GitHub 导入独立 Skill。正文通过 Harness 原生注册表按角色作用域读取，每步冻结实际版本与来源；导入记录实际提交，仓库脚本不会自动运行。

首次请求前提供真实 QQ、昵称与相关群名片，提及和引用按账号身份识别。角色持续演绎初始设定和当前人格，发送边界拒绝明确的宿主身份自称。

管理员权限由配置的 QQ 与真实消息发送者核验，普通输入不能授予危险操作权限；管理员与普通消息分别接纳，嵌套工具仍经过检查。普通交流可以读取自己的工作资料，媒体与网页下载逐跳校验地址，媒体发送使用已登记的有效资源。

模型步骤完成后持久确认输入，迟到投递、重复事件及重启不会重新排队。待处理消息不会提前进入近期背景。前台回复与后台记忆整理分别推进；格式或依据错误提供可纠正反馈，辅助模型失败保留经历并报告延后状态。数据库与文件持久化故障仍停止依赖活动。

上下文压缩继续使用 Harness 自己的判断与配置，压缩前保存原始经历检查点。Schema 保持 4，旧角色默认没有额外 Skill 或管理员。升级保留原角色资料、会话与启停状态。QQ、私聊和空间发送验收关闭。
