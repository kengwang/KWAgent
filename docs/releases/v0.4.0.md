# KWAgent v0.4.0

- Panel 增加重置对话、删除角色、确认界面和修订冲突处理。
- 当前 Harness 会话归档后自动创建新会话，保留角色启停状态、人格、长期记忆、绑定及 KWAgent 目标与计划。
- 删除角色停止活动、取消安排、停用扩展并释放绑定，保留原始记录与历史详情。角色 ID 为历史归属保留。
- 会话管理使用持久操作日志，重启继续相同目标；旧会话已接纳输入和历史工具不会重放。未接纳输入重新装配感知，原始批次继续保存。
- Schema 4 增加角色删除标记和活动角色索引，迁移前保存一致快照。镜像升级验收覆盖 Schema 1、2、3。

运行方式及命令见 [角色管理](../role-lifecycle.md)。模型容量和自动压缩继续由 Harness 管理。
