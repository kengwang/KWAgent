# KWAgent v0.6.2

角色编辑页增加“对话推理等级”，显示所选模型声明的档位及提供商默认值。每个角色可以独立选择，保存从下一模型步骤生效，重启和会话重置继续保留。辅助模型请求沿用现有策略。

保存前校验模型支持的档位，不支持的值明确返回错误。局部修改仅提交实际提供的字段，角色状态、绑定、人设及其他配置保持各自的当前值；版本冲突继续保留编辑内容。

`role.prepare` 提供配置值、当前模型选择及生效等级。旧资料兼容读取，已有角色和 Session 保留。模型上下文容量及压缩策略继续由 Harness 决定。

Lagrange Skill 和消息工具说明列出图片 `summary`、视频 `thumb_uri` 及转发卡片字段的必填、可空规则。媒体工具说明区分本地路径 `uri`、远端资源 `resourceId` 和已登记媒体 `mediaId`；新感知提供真实附件的准备与读取参数，已经固定的感知批次保持原内容。

记忆参考资料提供完整 `memory_revise` 创建格式、当前修订号和真实来源的获取方法，区分连续性记录的 `data` 与长期记忆的 `memory`。版本与来源校验继续执行。
