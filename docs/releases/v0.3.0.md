# KWAgent v0.3.0

- 增加当前生活、人物相处理解、未完话头、交流判断、情境表达、短期反思和日记。
- 新增 continuity_read、continuity_revise，沿用来源、修订号、完整负载和角色归属检查。
- 情绪与反思具有有效期限；话头结束后取消复核，未来适用、暂停恢复和计划修改均重新核验。
- 真实工具执行通过独立执行身份关联PTC父子调用；失败、未知及内部想法保留各自语义。
- 每步冻结生活、关系、记忆及实际交流背景；表达和反思各最多两条，连续性预算包含在原记忆预算中。
- 专用kwagent preset继承宿主工具，挂载MindCompaction并在压缩前提交记忆，摘要默认8192 Token。
- Panel增加连续性查看和编辑、来源分页、修订历史、冲突保留与复核安排。
- 数据库升级到Schema 3。升级前需要完整备份；旧Schema 1/2另存一致快照，原始经历和旧版本继续保留。
- GitHub Actions验证真实SQLite、断网镜像、旧版本数据升级与完整备份恢复，发布GHCR镜像、SBOM和构建来源记录。

运行使用Node.js 24.18.0，依赖使用Bun 1.4.2，Harness兼容0.2.2-alpha.2。

部署使用 `ghcr.io/kengwang/kwagent:0.3.0` 或对应完整SHA镜像。已有v0.1.0、v0.2.0标签及镜像保持不变。
