# v0.9.0

创建角色支持一句话生成完整角色与世界，使用所选全局聊天方案，生成的初始设定、人格、自我状态、表达示例及世界条目可编辑后一起保存。角色和世界原子创建，保留人工确认来源；初始世界进入角色背景，失败保留草稿。

日常背景检索改为本地中文分词与 FTS5。`memory_recall` 默认本地检索，显式语义扩展成功后复用二十四小时，检索结果始终读取当前记忆。

自动整理合并短批次，只携带相关旧认识。新消息继续处理，已经开始的整理不会因消息到达取消。暂停、停止及维护仍取消并等待执行结束，后台修订保持来源和活动归属。

整理格式补全使用已知版本，不推断来源；错误草稿在容量允许时通过局部 JSON Patch 修正，冲突重新读取。重复失败逐步延长重试间隔，原始经历和未完成分片持续保存。没有新增模型 Token 上限，不手动触发压缩。

通过真实模型、SQLite、Harness 和浏览器验证；发布镜像沿用 GHCR、单一 Compose 与 `1panel-network`。
