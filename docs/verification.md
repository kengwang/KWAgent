## 仍需外部条件的验收

- 专用 QQ 测试群或联系人尚未指定。文字、媒体、文件、合并转发和富消息的真实发送回执及客户端呈现尚未完成验收。Skill 中的能力说明依据实际 Schema 和发送实现，明确区分编码实现与账号验证。
- 当前远程 Milky 对非空群历史窗口曾返回 `Endpoint invocation failed`。空窗口可查询，非空历史恢复的远程验收仍受此接口结果限制。失败保留核对位置并显示原因。
- 聊天网关在连续模型验收期间返回过 `model_busy` 和上游请求过多。相关活动停止并保留原始事件；模型验收需要在接口可用时顺序执行。

- Git 当前没有配置远程地址。提交、标签和本地镜像可以生成，远程推送与镜像仓库发布尚未执行。
