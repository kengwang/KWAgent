# 一句话生成角色与世界

在“创建角色”中选择全局聊天模型方案，填写“角色创意”，点击“生成角色与世界”。生成请求使用该方案，推理等级沿用角色表单的覆盖或方案默认值。

草稿包含标识、名称、初始设定、当前人格、自我状态、表达示例、世界模式和世界条目。初始设定涵盖身份来历、性格、价值观、兴趣习惯、相处方式、处境、持续关注及能力边界；世界条目保存环境、规则、地点、历史和社会背景。生成结果填入原有表单，可以逐项编辑或移除世界条目，再保存角色。

生成过程保存全局 `role_generate` 操作及实际用量，生成完成后才返回草稿。JSON 格式或字段不符合要求时，最多请求一次修正，并记录两次实际结果。失败保留创意和手工输入。点击保存时，角色、世界条目与人工确认来源在同一事务创建；任何一项失败均不产生部分创建结果。重复的建议标识由宿主分配新的后缀，也可以手动修改。

虚构世界保存为 `world` 类型、`fictional` 认识，现实条目保存为 `inferred` 认识。生成和人工确认本身不证明外部事实。初始世界条目具有持续关注权重，参与角色首次背景；完整内容可从世界页面继续阅读、修订和查看来源。

管理入口共用 Operations 和 Typert：`role.generate` 接收 `{idea, chatPresetId, reasoningEffort?}`；`role.create` 兼容原有参数，并允许 `world` 数组和可选的 `generationId`。生成请求只产出草稿，角色的账号绑定、管理员、Skill、模型方案及启用由管理表单配置。
